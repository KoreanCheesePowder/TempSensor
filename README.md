# C.P TempSensor 0.1C v1.6.0

SONOFF 온습도 센서를 위한 SmartThings Edge 드라이버입니다.

## 주요 기능

- 온도와 습도를 원하는 정밀도로 반올림해 표시
- 온도·습도 보정값 적용
- 온도·습도 변화 보고 기준과 최소 보고 간격 설정
- 센서 정기 보고 주기 설정
- 절전 체크인 주기, 빠른 폴링 간격, 빠른 폴링 유지 시간 설정
- 설정 변경 후 센서가 깨어나면 대기 중인 설정을 자동 적용
- 배터리와 펌웨어 정보 조회
- 온도·습도 기록 저장 여부 선택
- SmartThings 요약정보에 온도와 습도를 함께 표시

## 설치

1. SmartThings CLI를 설치하고 로그인합니다.
2. `SETUP-AND-INSTALL.cmd`를 실행합니다.
3. 안내에 따라 채널과 허브를 선택합니다.
4. SmartThings 앱을 완전히 종료한 뒤 다시 실행합니다.

## 설정 참고

1초 또는 5초처럼 짧은 체크인·보고 주기는 센서 응답을 빠르게 만들지만 배터리 소모를 크게 늘릴 수 있습니다. 설정값은 센서 펌웨어가 지원하는 범위 안에서 적용됩니다.
